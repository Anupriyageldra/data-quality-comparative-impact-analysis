# Data Quality & Comparative Impact Analysis

## Project Overview

This project focuses on performing comprehensive Exploratory Data Analysis (EDA), data quality assessment, and comparative impact analysis on two datasets: Previous Output and Current Output.

The primary objective is to evaluate changes between dataset versions, identify data quality issues, measure inconsistencies, and understand the overall impact of data modifications through structured statistical analysis and visual reporting.

Using Python and its data analytics libraries, the project automates dataset profiling, validation, comparison, and report generation. The final results are presented through organized Excel workbooks containing comparison tables, analytical summaries, and graphical visualizations.

## Objectives

- Perform comprehensive Exploratory Data Analysis on both datasets.
- Identify duplicate records and measure data duplication.
- Calculate total missing values and column-wise null distributions.
- Evaluate data consistency and identify potential inconsistencies.
- Compare dataset dimensions, including rows and columns.
- Identify newly added and removed columns.
- Analyze differences between previous and current dataset versions.
- Generate structured Excel reports with comparison tables and charts.
- Evaluate the impact of changes on overall data quality.

## Key Features

### 1. Exploratory Data Analysis (EDA)
- Dataset dimensions and structural overview.
- Column names and data type analysis.
- Descriptive statistical summaries.
- Unique value analysis.
- Missing data distribution.

### 2. Data Quality Assessment
- Duplicate record identification.
- Total and column-wise null value calculation.
- Data type consistency checks.
- Missing data percentage analysis.
- Categorical value profiling.
- Potential data inconsistency identification.

### 3. Comparative Impact Analysis
- Previous vs. Current dataset comparison.
- Added and removed column identification.
- Record count comparison.
- Duplicate and missing value comparison.
- Column-wise data quality assessment.
- Identification of changes between dataset versions.

### 4. Automated Excel Reporting
The project generates an Excel-based analytical report containing:

- Dataset comparison summary.
- Missing value comparison tables.
- Duplicate record reports.
- Data consistency assessment.
- Added and removed column reports.
- Statistical comparison tables.
- Embedded charts and graphical summaries.

## Project Workflow

1. Load Previous and Current datasets.
2. Perform initial dataset profiling.
3. Analyze missing values and duplicate records.
4. Examine data types and consistency.
5. Compare dataset structures and statistical summaries.
6. Identify changes between dataset versions.
7. Generate comparative tables and visualizations.
8. Export the complete analytical report into Excel.
